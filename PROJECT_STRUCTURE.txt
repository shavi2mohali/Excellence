==================================================
PROJECT SUMMARY
==================================================

Frontend: React 18 single-page application with role-aware pages and components.
Backend: Firebase Functions v2 HTTPS backend for protected administrative operations.
Authentication: Firebase Authentication with application profiles and role checks stored in Firestore.
Database: Google Cloud Firestore.
Document Storage: Firebase Cloud Storage, with repository security rules and a document service.
Hosting: Cloudflare Workers static assets / Cloudflare Pages production deployment with SPA fallback.
Build Tool: Vite 6 with the React plugin; TypeScript project builds run before Vite.
Language: TypeScript and TSX primarily, with a small number of JavaScript support/data files and CSS.
Routing: React Router DOM using BrowserRouter and protected/admin route wrappers.
